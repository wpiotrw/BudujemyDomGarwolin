# Budujemy Dom – Dom w Garwolinie

Strona z raportem „Dom w Garwolinie – analiza działek i domów” (działki 2221 i 2224, obręb 0001 Miasto Garwolin).

Autor: Piotr Wiśniewski

## Zawartość

| Plik / folder | Opis |
|---|---|
| `index.html` | cała strona (HTML, style i skrypty w jednym pliku) |
| `img/` | wizualizacje, plany, mapy i wykresy |
| `.nojekyll` | GitHub Pages publikuje pliki bez przetwarzania przez Jekyll |

## Publikacja

Repozytorium: `wpiotrw/BudujemyDomGarwolin`. Strona jest publikowana pod adresem https://domgarwolin.azureme.pl przez GitHub Pages z gałęzi `main`, katalog główny (`/`). Każdy push do `main` aktualizuje stronę po ok. 1–2 minutach.

## Wersja publiczna

To repozytorium i strona są publiczne. Z raportu usunięto dane o dochodach i szacunek zdolności kredytowej rodziny – są tylko w prywatnej wersji raportu. Strona ma znacznik `noindex`, więc wyszukiwarki nie powinny jej indeksować.
